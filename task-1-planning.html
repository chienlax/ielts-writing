Writing Task 1 Planning

One reference for all seven task types. For each type: what the task is asking for, what to look for in the chart, and the three planning steps.

01. Line Chart time-based

Core task Describe how values change over time. The examiner wants to see trends, turning points, and comparative behaviour across lines, not just a list of data points.

What to notice

overall direction rate of change (steep vs gradual) peaks and troughs rank changes / crossovers convergence or divergence period of stability / plateau start and end values

Planning steps

Step 1 — Strip
Read the basics
  • Topic
  • X-axis: time range and unit
  • Y-axis: what is measured and unit
  • How many lines; what each represents
Step 2 — Flag
Mark key events per line
  • Start value → end value
  • Peak (value + year) or trough
  • Any crossover point
  • Periods of sharp change vs stability
Step 3 — Group
Decide paragraph structure
  • Group by trend direction (rising vs falling)
  • Or group by time period (early half / late half)
  • Keep crossovers and shared patterns in one paragraph
Key pitfall

Listing every data point in order is narrating, not reporting. Select the most significant values and describe the movement between them. Two or three well-chosen figures per line are enough.

02. Bar Chart categorical comparative

Core task Compare values across categories, which may be at a single point or across a few time periods. The main job is ranking and gap size, not time trends.

What to notice

highest and lowest category ranking order gap between top and bottom similar-performing categories outliers rank shifts across groups or years

Planning steps

Step 1 — Strip
Read the basics
  • Topic
  • What each bar represents
  • Unit (%, number, etc.)
  • Number of groups or time labels
Step 2 — Flag
Rank and note gaps
  • Rank all bars highest to lowest
  • Identify clear outliers
  • Note categories that are close in value
  • If multiple groups: note any rank reversals
Step 3 — Group
Decide paragraph structure
  • Top tier vs bottom tier
  • Or group by trend if time-series bars
  • One group per paragraph; avoid listing all categories in one sentence
Key pitfall

Describing every bar in descending order without grouping reads as a list. If three categories are broadly similar in value, name them together with a comparative phrase rather than three separate sentences.

03. Pie Chart proportional

Core task Report how a whole is divided into proportions. When two pies are given, the task is to compare how those proportions shift between them.

What to notice

dominant segment (>50% or much larger) smallest segment segments that are roughly equal combined minor segments vs dominant if two pies: segments that grew / shrank

Planning steps

Step 1 — Strip
Read the basics
  • Topic; what the whole represents
  • Category labels and % values
  • Year / place if stated
  • Number of pies (one or two)
Step 2 — Flag
Rank and tier
  • Rank segments largest to smallest
  • Group into: dominant / mid-tier / minor
  • If two pies: annotate increase or decrease per segment
Step 3 — Group
Decide paragraph structure
  • Single pie: dominant tier → mid and minor
  • Two pies: P1 largest segments in both; P2 smaller segments and shifts
Key pitfall

Reading out every percentage in order is not analysis. Group segments and use comparative language: nearly half, just over a third, combined, these three categories accounted for...

04. Table multi-dimensional

Core task Compare data across two dimensions simultaneously (rows and columns). Select the most significant patterns; you cannot and should not report every cell.

What to notice

overall highest and lowest cell pattern along each row pattern down each column outlier cells (unusually high or low) consistent rankings across rows notable exceptions to a general pattern

Planning steps

Step 1 — Strip
Read the basics
  • What rows represent
  • What columns represent
  • Unit of measurement
  • Any total row or column
Step 2 — Flag
Scan for patterns
  • Circle the highest and lowest cell overall
  • Note any column where one row consistently leads
  • Identify any row that breaks the general column pattern
Step 3 — Group
Choose an axis
  • Organise by row (compare categories at each column value)
  • Or organise by column (describe how each column behaves across rows)
  • Stick to one axis per paragraph
Key pitfall

Transcribing the table row by row produces a wall of numbers. Pick a clear analytical angle (e.g., "Country A consistently led in all categories except X") and build paragraphs around that argument rather than the table's physical layout.

05. Mixed / Two Charts linked

Core task Understand each chart individually, then report the relationship or contrast between them. The connection between the two charts is usually the most important point.

What to notice

what each chart measures (different metrics?) do the trends agree or contradict? shared categories between the two charts which chart shows quantity; which shows rate or proportion any category that is notable in both

Planning steps

Step 1 — Strip
Analyse each chart separately
  • Apply the single-chart strip to each one
  • Identify the metric each chart shows
  • Check whether time periods or categories match
Step 2 — Connect
Find the link
  • Does chart 2 explain chart 1 (cause → effect)?
  • Are they showing the same data at different scales?
  • Which category behaves consistently across both?
  • Is there a surprising mismatch?
Step 3 — Structure
One paragraph per chart
  • Describe chart 1 in P1, chart 2 in P2
  • Cross-reference once per paragraph where the connection is clear
  • Overview covers the link, not just each chart in isolation
Key pitfall

Treating the two charts as completely independent and writing two separate mini-reports misses the point. The overview must capture how the charts relate. At least one cross-reference per body paragraph keeps the analysis unified.

06. Process Diagram sequential

Core task Describe how a raw input is transformed into an output through a series of stages. The task rewards grouping stages into logical phases, not listing every step with First/Then/Next.

What to notice

raw input and final output total number of stages stages where the material changes form any branch or loop natural phase boundaries (e.g., field → factory) parallel stages happening simultaneously

Planning steps

Step 1 — Strip
Read the basics
  • Natural or manufactured process?
  • Count stages
  • Raw material → final product
  • Any branches or cycles?
Step 2 — Table
Inventory each stage
  • Stage number, label, what happens
  • Flag: form-change ★, branch ⤶, unusual !
  • Group stages into 2–3 umbrella phases
Step 3 — Paragraph plan
One paragraph per phase
  • Use umbrella terms: initial preparation, processing, distribution
  • Vary cohesive devices: time clauses, reduced relatives, passive
  • Overview: type of process + N stages + raw → final
Key pitfall

Chaining First... Then... Next... Finally... through all stages is Band 6 cohesion. Use subordinate time clauses: Once the cane has been harvested..., After being crushed, the juice is..., The dried pellets are then packed, completing the cycle.

Dominant verb form

Present passive throughout: is heated, is crushed, is transferred. Time clauses with present perfect passive: once the crop has been harvested. Never past tense unless the question explicitly shows a historical process.

07. Map / Plan spatial

Core task Describe how a place changed between two points in time (or how a planned development differs from the current state). The task rewards grouping changes into categories, not cataloguing features compass point by compass point.

What to notice

what was added (+) what was removed (−) what was relocated (⇄) what was expanded (↑) or reduced (↓) what was retained (=) overall dominant transformation

Planning steps

Step 1 — Strip
Read the basics
  • Place name
  • Time 1 and Time 2 (or present vs planned)
  • Compass orientation
  • Scale / key if present
Step 2 — Inventory
List every feature
  • Feature | Time 1 state | Time 2 state | Change flag
  • Group features: indoor / outdoor / access / amenity
  • Identify which group has the most change
Step 3 — Paragraph plan
Before then after
  • P1: original layout (what existed)
  • P2: all changes (grouped by category, not location)
  • Overview: dominant transformation + what was retained
Key pitfall

Writing "The first map shows... The second map shows..." produces two disconnected picture descriptions. Structure around what changed: "The most significant changes involved the outdoor facilities, which were relocated..." Forces comparison into the sentence itself.

Tense logic

Past-to-present map: P1 in simple past (the building contained); P2 in present perfect (the cafe has been moved). Present-to-future plan: P1 in simple present (there are two meeting rooms); P2 in future passive (a third room will be added). Never "is planned to be" — use "will be" or "is to be".

08. Writing the Overview

The overview is the most important paragraph. It appears after the introduction, before the body, and contains no data figures. It tells the examiner you can see the whole picture, not just individual points.

Task type Overview must contain Overview must NOT contain
Line General direction of each line; which line was highest overall; any major crossover Specific years, exact values, every data point
Bar Which category was consistently highest/lowest; whether ranking was consistent or shifted Specific figures; listing every bar
Pie Which segment dominated; combined share of the largest group; what was negligible Exact percentages; listing all slices
Table Which row/column had the highest overall values; any consistent pattern or notable exception Cell-by-cell detail; total figures
Mixed What each chart shows; the key relationship or contrast between them Data figures; treating charts as unrelated
Process Type of process; total number of stages; raw input and final output Step-by-step detail; copied diagram labels
Map The dominant transformation; main categories affected; what was retained Compass directions; list of individual buildings; evaluative adjectives
Overview skeleton (data charts)

Overall, [subject A] showed the most significant [increase / variation] over the period, while [subject B] remained comparatively [stable / low]. A notable feature was [crossover / peak / gap] in [approximate period].

Overview skeleton (process)

Overall, the diagram illustrates a [natural / man-made] process consisting of [N] stages, through which [raw material] is transformed into [final product][, with a recycling loop at stage X].

Overview skeleton (map)

Overall, the [area / building] underwent considerable development between [time 1] and [time 2], with the most significant changes affecting [category]. Several features, including [X and Y], remained largely unchanged.

09. Tense Cheat Sheet

Task type Primary tense Watch out for
Line, bar, pie, table (historical data) Simple past: rose, fell, accounted for Mixing present and past randomly
Line, bar, pie, table (no year given) Simple present: shows, represents, is Do not assume it is historical
Process Present passive: is heated, is transported Active voice (workers heat) and past tense
Map: past → present P1 simple past; P2 present perfect passive: has been added Using simple present for both paragraphs
Map: present → future P1 simple present; P2 future passive: will be added, is to be removed Is planned to be (incorrect passive); mixing future forms randomly

Time budget per task: 20 minutes total. ~3 min planning (Step 1: 30s — Step 2: 90s — Step 3: 30s), ~15 min writing, ~2 min checking tense and overview.
